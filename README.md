# Data Science Internship - Logic Building Tasks

This repository contains solutions for 5 logic building tasks demonstrating fundamental programming concepts with real-world applications.

## Tasks Overview

### Task 1: User Login Check
Authentication system that validates username and password credentials.

### Task 2: Pass/Fail Analyzer
Analyzes student marks and calculates pass/fail statistics with percentage.

### Task 3: Simple Data Cleaner
Cleans and standardizes user names by removing spaces and converting to lowercase.

### Task 4: Message Length Analyzer
Analyzes message lengths and flags messages exceeding 10 characters.

### Task 5: Error Message Detector
Detects and counts error messages from system logs with detailed breakdown.

## Files

- `internship_tasks.ipynb` - Main submission file (Jupyter Notebook)
- `task1_user_login.py` - Task 1 solution
- `task2_pass_fail_analyzer.py` - Task 2 solution
- `task3_data_cleaner.py` - Task 3 solution
- `task4_message_analyzer.py` - Task 4 solution
- `task5_error_detector.py` - Task 5 solution
- `run_all_tasks.py` - Execute all tasks at once

## How to Run

### Jupyter Notebook (Recommended)
Open `internship_tasks.ipynb` in Jupyter Notebook or Google Colab and run all cells.

### Python Files
```bash
python task1_user_login.py
python task2_pass_fail_analyzer.py
python task3_data_cleaner.py
python task4_message_analyzer.py
python task5_error_detector.py
```

### Run All Tasks
```bash
python run_all_tasks.py
```
